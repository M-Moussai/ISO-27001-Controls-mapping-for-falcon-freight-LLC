| Control ID | Control Name | ISO 27002 Guidance Summary | How Falcon Freight Implements It | Status |
|---|---|---|---|---|
| A.5.1 | Policies for Information Security | 27002 says top management should define, approve, and communicate a security policy that's reviewed regularly. | Falcon Freight's CEO approves an Information Security Policy annually, distributed to all staff via email and the HR onboarding portal. | Implemented |
| A.5.15 | Access Control | 27002 recommends access rights based on business need, reviewed periodically, following least-privilege. | Falcon Freight uses role-based access in its fleet tracking and finance systems; IT reviews access lists quarterly and removes access within 24 hours of an employee's exit. | Implemented |
| A.7.4 | Physical Security Monitoring | 27002 recommends monitoring premises to detect unauthorized physical access. | Falcon Freight's Dubai warehouse uses CCTV covering all entry points, retained for 90 days, reviewed monthly by the Facilities team. | Partial |
| A.5.9 | Inventory of Information and Assets | 27002 recommends maintaining an inventory of information and associated assets, with an owner assigned to each. | Falcon Freight maintains an asset register in a shared spreadsheet listing all laptops, servers, and the fleet tracking database, each with a named IT owner. | Implemented |
| A.5.18 | Access Rights | 27002 says access rights should be granted, reviewed, and revoked according to the organization's access control policy. | New hires get system access provisioned by IT within 24 hours of start date, based on their role; access is fully revoked on their last working day. | Implemented |
| A.5.24 | Information Security Incident Management Planning | 27002 recommends defined roles, procedures, and escalation paths for handling security incidents. | Falcon Freight has a 1-page incident response plan naming the IT Manager as first responder, with escalation to the CEO for incidents affecting customer data. | Partial |
| A.6.1 | Screening | 27002 recommends background verification checks on candidates before employment, proportional to the role's risk. | Falcon Freight runs employment history and reference checks on all new hires; finance and IT roles get an additional criminal background check. | Implemented |
| A.6.2 | Terms and Conditions of Employment | 27002 recommends employment contracts state the employee's and company's information security responsibilities. | All Falcon Freight employment contracts include a confidentiality clause and reference to the Acceptable Use Policy. | Implemented |
| A.6.3 | Information Security Awareness, Education and Training | 27002 recommends regular, role-relevant security training for all personnel. | Falcon Freight runs a mandatory 30-minute security awareness session at onboarding, plus an annual refresher for all staff. | Implemented |
| A.6.5 | Responsibilities After Termination or Change of Employment | 27002 recommends that security duties surviving termination (e.g. confidentiality) be defined and communicated. | Falcon Freight's exit checklist includes a signed reminder of ongoing confidentiality obligations and immediate access revocation. | Implemented |
| A.6.7 | Remote Working | 27002 recommends rules to protect information accessed, processed, or stored at remote working sites. | Falcon Freight requires VPN use for remote access to internal systems and prohibits saving customer data to personal devices. | Partial |
| A.7.1 | Physical Security Perimeters | 27002 recommends defined security perimeters to protect areas containing sensitive information and assets. | Falcon Freight's Dubai office and warehouse are enclosed by a badge-access perimeter fence with a single monitored entry point. | Implemented |
| A.7.2 | Physical Entry | 27002 recommends secure entry controls to ensure only authorized personnel access facilities. | Employees use RFID badges for entry; visitors must sign in and are escorted at all times in the warehouse. | Implemented |
| A.7.10 | Storage Media | 27002 recommends managing storage media through its lifecycle, including secure disposal. | Falcon Freight logs all USB drives issued to staff and requires IT to wipe them before reissue or disposal. | Not Implemented |
| A.8.5 | Secure Authentication | 27002 recommends secure authentication technologies and procedures based on access restrictions and policy. | Falcon Freight requires multi-factor authentication (MFA) for email and the finance system; MFA for the fleet tracking system is planned for next quarter. | Partial |
| A.8.7 | Protection Against Malware | 27002 recommends malware detection, prevention, and recovery controls combined with user awareness. | Falcon Freight runs endpoint antivirus with automatic daily updates across all company devices. | Implemented |
| A.8.13 | Information Backup | 27002 recommends backup copies of information, software, and systems tested regularly per an agreed policy. | Falcon Freight backs up its customer database nightly, with monthly restore tests performed by IT. | Implemented |
| A.8.24 | Use of Cryptography | 27002 recommends rules for the effective use of cryptography, including key management. | Customer payment data is encrypted in transit (TLS) and at rest in Falcon Freight's database; encryption keys are rotated annually by IT. | Partial |
