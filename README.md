# Falcon Freight ISMS: ISO 27001 Controls Mapped to ISO 27002 Guidance

A simulated Information Security Management System (ISMS) project mapping 
ISO 27001 Annex A controls to ISO 27002 implementation guidance for a 
fictional logistics company based in Dubai, UAE.

## Why I built this

I completed an ISO 27001 Information Security Management system course and wanted to prove I could apply the 
standard to a real-feeling business, not just recognize the control names. 
This project walks through what it actually looks like to implement 20 
Annex A controls for a company handling customer data, payments, and 
physical assets.

## What's inside

- `docs/company-profile.md` — background on the fictional company, Falcon Freight LLC
- `docs/scope.md` — the ISMS scope statement
- `docs/control-mapping.md` — 23 Annex A controls mapped to ISO 27002 guidance, 
  with implementation status (Implemented / Partial / Not Implemented)

## Controls covered

Organizational, People, Physical, and Technological controls — spanning access 
control, physical security, incident management, backups, cryptography, and more.
